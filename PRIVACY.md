# Privacy Policy: WebMCP Recorder

_Last updated: 11 October 2026_

WebMCP Recorder records tasks you choose to teach it on websites and replays them for you. It is built to keep everything on your own computer.

## What it handles
- **Tasks you teach:** the steps you took (which fields you filled, which buttons you clicked, with the labels the website shows), the values you entered, and the request the website sent when you saved. These are stored in your browser's local extension storage.
- **Run results:** the last result of each task (for example "Invoice INV-104 saved").
- **Spreadsheet rows you paste or drop:** used only to run your task, and not stored after you close the panel.

## What it never does
- It does not send any data to the developer or to any third party. There is no server, no analytics and no account.
- It does not record passwords. Login headers, cookies and security tokens are not saved in tasks; replays reuse the sign-in session you already have in your browser.
- It does not sell, share or use data for advertising or credit decisions.

## Where data goes
When you run a task, the extension sends the same kind of request to the same website you taught it on, exactly as if you had done it yourself. If you let an AI agent in your browser call a task (through WebMCP), that agent receives the task's result.

## Your control
- Delete any task from the side panel; removing the extension deletes all its data.
- Export and import are files you create and share yourself.
